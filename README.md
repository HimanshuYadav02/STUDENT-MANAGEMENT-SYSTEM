# Himanshu SM- Student Study Dashboard

Himanshu SMis a lightweight, modern, and interactive study dashboard designed for students to manage schedules, track daily study goals, stay focused with a Pomodoro timer, and organize subjects efficiently.

---
## Live Demo

* **Live Preview:** [Click Here to View Live Project](https://HimanshuYadav02.github.io/STUDENT-MANAGEMENT-SYSTEM/)
* **Source Code:** [GitHub Repository](https://github.com/HimanshuYadav02/STUDENT-MANAGEMENT-SYSTEM)

## 🚀 Features

* **📊 Dynamic Dashboard**: Track scheduled study blocks, task completion rates, and real-time study metrics.
* **📅 Interactive Study Calendar**: Full monthly calendar view to navigate dates and manage monthly study schedules.
* **📝 Task & Subject Manager**: Add custom study sessions, tag subjects, and mark tasks complete with automatic progress calculation.
* **⏱️ Integrated Pomodoro Timer**: Built-in 25-minute focus timer with Start, Pause, and Reset controls.
* **📁 Materials & Practice Test Hub**: Dedicated UI tabs for accessing study material and taking practice quizzes.
* **⚙️ Profile Customization**: Update display name in settings with instant dashboard profile updates.

---

## 🛠️ Tech Stack

* **HTML5**: Structured markup and layout components.
* **CSS3**: Responsive layouts using CSS Grid, Flexbox, and CSS Variables.
* **JavaScript (ES6)**: State management, DOM manipulation, interactive calendar rendering, and timer logic.
* **Font Awesome**: Modern vector icons.
