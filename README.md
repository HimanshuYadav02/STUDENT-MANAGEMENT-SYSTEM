# Himanshu SM- Student Study Dashboard

Himanshu SM  ek modern, lightweight aur clean study dashboard web application hai. Yeh students ko unki study schedule manage karne, dynamic tasks track karne, focus timer (Pomodoro) use karne aur study plans organise karne me madad karta hai.

---

## 🚀 Features

* **📊 Dynamic Dashboard**: Scheduled study blocks, task completion rate, aur overall study metrics tracking.
* **📅 Interactive Calendar View**: Full monthly calendar view jisme dates navigate karne aur monthly timeline dekhte banta hai.
* **📝 Task & Subject Manager**: Custom study sessions add/delete karne aur subjects mark-complete karne ki functionality.
* **⏱️ Pomodoro Focus Timer**: Built-in 25-minute study timer with Start, Pause, and Reset options.
* **📁 Materials & Practice Tests Section**: Notes aur practice tests organise karne ke liye Dedicated UI tabs.
* **⚙️ Profile Settings**: User profile name customisation direct dashboard greeting updates ke saath.

---

## 🛠️ Tech Stack

* **HTML5**: Semantic markup aur structural layout.
* **CSS3**: Modern UI layout, CSS Grid, Flexbox, aur custom variable styling.
* **JavaScript (ES6)**: Dynamic DOM manipulation, state management, timer logic, aur calendar rendering.
* **Font Awesome**: UI icons ke liye.
